# runtime-observability-dashboard

Lightweight runtime observability dashboard for multi-agent workflow monitoring, execution trace visualization, and runtime telemetry.

## Features

- Execution timeline visualization per workflow
- Structured runtime log viewer with JSON metadata
- Workflow detail drawer modal
- Agent handoff trace section
- Runtime status badges
- Workflow filtering by status
- Mock JSON runtime dataset (no backend dependency)

## Run locally

Open `index.html` directly in a browser.
